# Победа Радар

Android-приложение для наблюдения за ценами Победы (IATA: DP) на маршруте Москва (MOW) ⇄ Газипаша (GZP).

## Что умеет версия 1.0

- отдельный выбор диапазона дат для MOW → GZP и GZP → MOW;
- запрос Travelpayouts `aviasales/v3/get_special_offers` с фильтром `airline=DP`;
- дополнительная проверка, что ответ действительно от авиакомпании DP;
- фильтрация результатов строго по выбранному диапазону дат;
- минимум / средняя цена по найденным предложениям;
- оценка цены относительно текущей выборки;
- открытие найденного предложения на Aviasales;
- токен Travelpayouts вводится внутри приложения и хранится только на устройстве, в GitHub он не попадает.

## Сборка

Открыть корневую папку проекта в Android Studio. Использовать JDK 17. После Gradle Sync: Build → Build APK(s).

## Важно

Data API Travelpayouts возвращает цены, ранее найденные пользователями Aviasales; это не гарантирует наличие предложения у Победы в момент открытия. Поэтому в приложении есть переход на сайт для перепроверки.
